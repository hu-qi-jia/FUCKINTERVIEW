# 设置页表单规范

适用于 `src/components/pipecat/settings-dialog.tsx` 及后续同类表单。

## 1. 容器

| 项 | 规范 |
| --- | --- |
| 宽度 | `max-w-2xl`（672px），左右留 16px |
| 高度 | **固定 600px**，小屏用 `max-h-[88vh]` 兜底 |
| 结构 | 标题栏 56px → 标签栏 → 可滚动内容区 → 底栏 56px |
| 内容区 | `flex-1` + `overflow-y-auto`，切换标签页不改变弹窗尺寸 |

标题栏只写标题，不写副标题；底栏左侧留给状态，右侧固定「取消 / 保存设置」。

## 2. 栅格

- 模型配置：两列等宽 `grid gap-3 sm:grid-cols-2`，单列字段占满整行
- 通用设置：单列表单（`max-w-md`），每个字段占满整行
- 同一行的字段必须同时存在、同时隐藏；某个字段按供应商隐藏时，同行字段加 `sm:col-span-2`
- 列宽由栅格决定，**不允许字段自己设宽度**

## 3. 字段

```
label（12px，muted）
control（高 32px）
```

- 每个字段只有「标签 + 控件」两层，**不写字段下方的说明文字**
- 需要提示时写进 `placeholder`（示例值）或 `aria-label`
- 禁止用说明文字改变行高，这是之前字段错位的根因

## 4. 控件

| 控件 | 规范 |
| --- | --- |
| Input | 默认 `h-8`，占满所在列 |
| Select | 触发器 `h-8 w-full` |
| Textarea | `rows=7`，独占一行，`resize-none` |
| Button | 底栏 `size="sm"` |

## 5. 页面结构与字段顺序

设置页分两页：**通用设置**（单列）与 **模型配置**（三个分区，两列）。

| 分区 | 字段顺序 |
| --- | --- |
| 通用设置 | 界面语言、主题（单列整行） |
| 语音识别 ASR | 供应商 → 模型 / 识别语言 → Base URL → API Key |
| 对话模型 LLM | 供应商 → 模型 / Base URL → API Key → 系统提示词 |
| 语音合成 TTS | 供应商 → 模型 / 音色 → 语言 / Group ID → Base URL → API Key |

- 分区标题 14px semibold，置于字段上方
- 分区间距 24px，并用分隔线隔开
- 模型配置页整体可滚动，弹窗高度不变

## 6. 间距

- 弹窗内边距 `p-4`
- 字段纵向间距 `gap-3`（12px）
- 标签与控件 `gap-1.5`（6px）

## 7. 反馈

- 状态区固定在底栏左侧，内容为「保存中… / 已保存 / 错误信息」，空闲时留空
- 错误文字用 `text-destructive`，不弹窗、不抖动布局
